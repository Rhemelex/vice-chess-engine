# Chess Engine in C

A chess engine written in C, currently in early development.

## Current status
- Board representation and core definitions (`defs.h`)
- Initialization routines (`init.c`)

## Planned
- Move generation
- Search (alpha-beta)
- Position evaluation
- UCI protocol support

## Build
Open `vice.sln` in Visual Studio and build (x64).

## Acknowledgments
The initial structure follows Bluefever Software's VICE tutorial series.
